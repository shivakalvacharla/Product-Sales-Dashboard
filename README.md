# Product Sales Dashboard

An executive-level product sales dashboard tracking 150 transactions, regional revenue distribution, category-wise performance, and monthly sales trends.

![Product Sales Dashboard](PRODUCT%20%20SALES%20DASHBOARD%20IMAGE.png)

## Repository Structure
- `dataset.csv`: 150 rows of sales transactions.
- `SALES OF PRODUCT DASHBOARD.xlsx`: Excel workbook containing Raw Data, Pivot Tables, and visual Dashboard.
- `PRODUCT  SALES instructions.txt`: Dashboard layout specifications, KPI definitions, and chart configurations.
- `PRODUCT  SALES DASHBOARD IMAGE.png`: Screenshot of the finalized interactive Excel dashboard.

## Key Metrics Summary
- **Total Products Tracked**: 150
- **Total Revenue**: $9,210.91
- **Average Price**: $61.41
- **Average Units Sold**: 2.55
